# نور — موقع إسلامي جامع

موقع عربي (RTL) هادئ وأنيق، مبني بـ HTML وCSS وJavaScript فقط، بلا أي مكتبات أو خطوات بناء. يعمل على الجوال والحاسوب، ويدعم الوضعين الليلي والنهاري.

## المعاينة السريعة

```powershell
cd islamic-site
python -m http.server 8787
```

ثم افتح: <http://127.0.0.1:8787>

> يمكن فتح `index.html` مباشرة، لكن يُفضّل تشغيله عبر خادم محلي حتى تعمل خدمات المتصفح (تحديد الموقع، البوصلة، الحافظة) بشكل صحيح.

## الروابط العربية و SEO

| القسم | الرابط |
| --- | --- |
| الرئيسية | `/` |
| مواقيت الصلاة | `/اوقات-الصلاة` |
| القرآن الكريم | `/القرآن-الكريم` |
| الأذكار اليومية | `/الأذكار-اليومية` |
| المسبحة الرقمية | `/المسبحة-الرقمية` |
| أسماء الله الحسنى | `/أسماء-الله-الحسنى` |
| اتجاه القبلة | `/اتجاه-القبلة` |

- كل رابط صفحة مستقلة فعلية (ملف HTML) بعنوان `<title>` ووصف `meta description` و`canonical` و`JSON-LD` خاص بها — لا يعتمد على JavaScript للفهرسة.
- التنقل داخل الموقع يستخدم `history.pushState` (بلا إعادة تحميل)، وإعادة تحميل أي رابط مباشرة تعمل دون 404.
- روابط قديمة بالهاش (`#quran`) تُحوَّل تلقائيًا إلى المسار العربي الصحيح.
- اللغة العربية هي الأساس (`<html lang="ar" dir="rtl">` دائمًا). `?lang=en` يخصّ صفحة القرآن فقط ويضيف `noindex` لها؛ الـ canonical يبقى للرابط العربي.
- لتوليد الصفحات بعد أي تعديل على `index.html` أو `tools/routes.mjs`:

```powershell
npm run build
```

## المعاينة المحلية

```powershell
npm start
```

ثم افتح <http://127.0.0.1:8081> — الخادم يحاكي `cleanUrls` وإعادة توجيه الشرطة المائلة وصفحة 404 كما على Vercel.

## النشر على Vercel

1. اربط المستودع بـ Vercel (Framework Preset: **Other**).
2. الإعدادات مأخوذة من `vercel.json` تلقائيًا: `buildCommand` = `node tools/build-routes.mjs`، والمخرج `dist`، و`cleanUrls` مفعّل.
3. النطاق الرسمي معرّف في `tools/routes.mjs` (`DEFAULT_SITE_URL = https://noorislam.xyz`) ويُستخدم في `canonical` و`sitemap.xml`.
4. لتغيير النطاق: عدّل `DEFAULT_SITE_URL` ثم `npm run build`، أو اضبط متغيّر البيئة `SITE_URL` في Vercel (له الأولوية) وأعد النشر.

> الروابط العربية (Unicode) مدعومة: أسماء الملفات UTF-8، وVercel يفك ترميز المسار ويطابق الملف مباشرة، مع `cleanUrls` لإخفاء `.html`.

## كيف يعمل حساب المواقيت؟

- يعتمد على موقع الشمس (الميل والاعتدال الزمني) وحساب الزوايا الفلكية.
- يحسب الفجر والعشاء بزوايا طريقة الحساب المختارة، والعصر بظل المثل (المذهب الشافعي).
- يستخرج فرق التوقيت للمدينة من قاعدة بيانات المناطق الزمنية في المتصفح (`Intl`)، لذلك يتبع تحديثات التوقيت الصيفي تلقائيًا.
- كل الحساب يتم على جهاز الزائر، دون إرسال الموقع إلى أي خادم.

## البيانات والمصادر

- **القرآن (النص العثماني)**: واجهة [AlQuran Cloud](https://alquran.cloud/api) (نسخة `quran-uthmani`)، والتلاوة من `cdn.islamic.network`. عند تعذر الاتصال تُعرض نسخة محفوظة من الفاتحة والقصار.
- **الترجمة الإنجليزية**: Saheeh International (`en.sahih`) من AlQuran Cloud — ترجمة منشورة معتمدة، وليست ترجمة آلية.
- **التفسير العربي**: تفسير الميسر (مجمع الملك فهد لطباعة المصحف الشريف) عبر مستودع [spa5k/tafsir_api](https://github.com/spa5k/tafsir_api) مفتوح المصدر.
- **التفسير الإنجليزي**: Ibn Kathir (Abridged) عبر المستودع نفسه (نفس بيانات Quran.com).
- **الأرقام**: تُعرض جميع أرقام الموقع بالأرقام اللاتينية (0-9).
- **القبلة**: زاوية الدائرة العظمى من الشمال الحقيقي، مع تصحيح الانحراف المغناطيسي بمعاملات [NOAA WMM-2025](https://www.ncei.noaa.gov/products/world-magnetic-model) (ملكية عامة) داخل `wmm.js` — بلا أي خدمة خارجية. البوصلة تقرأ `webkitCompassHeading` على iOS، وتحسب الاتجاه من مصفوفة الدوران على أندرويد، مع تنعيم ومؤشر جودة.
- **الخطوط**: Amiri وTajawal عبر Google Fonts، مع بدائل نظامية إذا تعذر تحميلها.
- **الأذكار والأحاديث والأسماء**: نصوص مأثورة مضمّنة في `data.js`، ويُنصح بالرجوع إلى المصادر الأصلية عند النشر العام.
- **المواقيت**: تقديرية، وقد تختلف دقائق قليلة عن تقويم مسجدك أو الجهة الرسمية في بلدك.

## روابط عميقة

- صفحة القرآن تحفظ الموضع في الرابط: `/القرآن-الكريم?surah=2` أو `/القرآن-الكريم?page=50`.
- الوضع الإنجليزي لصفحة القرآن: `/القرآن-الكريم?lang=en` (يُضاف تلقائيًا عند الضغط على زر `EN`).

## التخصيص

- **الألوان والخطوط**: عدّل المتغيرات في أعلى `assets/css/style.css`.
- **المدن**: أضف عنصرًا إلى مصفوفة `cities` في `data.js` بالحقول: `name`, `country`, `lat`, `lng`, `tz`.
- **طرق الحساب**: أضف إلى `methods` زاوية الفجر والعشاء (أو دقائق العشاء إذا كانت أكبر من 60).
- **الأذكار والأسماء**: عدّل المصفوفات في `data.js` مباشرة.
- **المدينة الافتراضية**: غيّر `'الدار البيضاء'` في `app.js` (دالة `initSelects`).

## النشر

الموقع ثابت بالكامل، ويمكن نشره مجانًا على:

- GitHub Pages: ارفع محتويات المجلد إلى فرع `gh-pages`.
- Netlify / Vercel / Cloudflare Pages: اسحب المجلد أو اربط المستودع، دون أمر بناء.
- أي استضافة ملفات ثابتة.

## ملاحظات

- تحديد الموقع والبوصلة يحتاجان سياقًا آمنًا (`https` أو `localhost`).
- البوصلة تعمل على الأجهزة التي تدعم `DeviceOrientationEvent`؛ وإلا فاستخدم بوصلة خارجية.
- وضع الكاميرا (AR) يستخدم `getUserMedia` و`DeviceOrientation`، ويحتاج إذن الكاميرا وإذن الحركة/الاتجاه، وسياقًا آمنًا.
- دقة البوصلة تعتمد على مستشعر الهاتف؛ ابتعد عن المعادن، وحرّك الهاتف على شكل 8 قبل الاعتماد على القراءة.
- حاسبة المواقيت لا تعالج حالات خطوط العرض القصوى التي لا تختفي فيها الشمس تمامًا.
- لا توجد أي أدوات تتبع أو إعلانات.
